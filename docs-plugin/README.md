### [02-플러그인-상세분석.md](./02-플러그인-상세분석.md)
**기존 플러그인 심층 분석**

- commit-commands: Git 워크플로우 자동화
- feature-dev: 7단계 기능 개발 워크플로우
- pr-review-toolkit: 6가지 전문 PR 검토 에이전트

- learning-output-style: 대화형 학습 모드

각 플러그인의 코드, 구조, 동작 방식을 상세하게 분석합니다.

**읽어야 할 사람**: 플러그인 내부 동작을 이해하고 싶은 사람, 유사한 플러그인을 만들려는 사람

## 🛠️ 개발 환경 설정

플러그인 개발에 유용한 도구:

### JSON 검증
```bash
# jq로 JSON 유효성 검사
cat .claude-plugin/plugin.json | jq .
cat hooks/hooks.json | jq .
```

### 마크다운 미리보기
- VSCode: Markdown Preview
- 터미널: `glow`, `mdcat`

### Hook 스크립트 테스트
```bash
# Hook 입력 시뮬레이션
echo '{"session_id":"test","tool_name":"Write","tool_input":{"file_path":"test.ts","content":"test"}}' | \
  ./hooks-handlers/your-hook.py

# 종료 코드 확인
echo $?
```

## 📝 예제 플러그인 아이디어

제작 가이드를 공부한 후 만들어볼 만한 플러그인들:

### 초급
- **타임스탬프 삽입기**: 현재 시간을 파일에 삽입하는 명령어
- **파일 통계**: 프로젝트 파일 통계를 보여주는 명령어
- **TODO 추출기**: 코드에서 TODO 주석을 찾는 에이전트

### 중급
- **API 문서 생성기**: API 엔드포인트 문서를 자동 생성하는 에이전트
- **종속성 체커**: 순환 종속성을 찾는 에이전트
- **커밋 메시지 검증기**: 커밋 메시지 규칙을 체크하는 Hook

### 고급
- **마이그레이션 도구**: 코드 마이그레이션 워크플로우 (Commands + Agents)
- **성능 프로파일러**: 성능 측정 및 최적화 제안 (Agents + Hooks)
- **코드 리뷰 자동화**: PR 자동 리뷰 시스템 (Commands + Agents + Hooks)
