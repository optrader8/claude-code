## 플러그인이란?

Claude Code 플러그인은 Claude의 기능을 확장하는 모듈형 컴포넌트입니다. 플러그인을 통해 다음과 같은 기능을 추가할 수 있습니다:

- **슬래시 명령어 (Commands)**: `/commit`, `/feature-dev` 같은 사용자 정의 명령어
- **전문 에이전트 (Agents)**: 특정 작업을 수행하는 독립적인 AI 에이전트
- **훅 (Hooks)**: 특정 이벤트 발생 시 자동으로 실행되는 스크립트

---

## 플러그인의 유형

### 1. Commands 플러그인
사용자가 `/명령어` 형식으로 호출할 수 있는 슬래시 명령어를 제공합니다.

**예시**: `/commit` - git 커밋을 자동으로 생성

### 2. Agents 플러그인
특정 작업을 전문적으로 수행하는 AI 에이전트를 제공합니다.

**예시**: `code-explorer` - 코드베이스를 심층 분석하는 에이전트

### 3. Hooks 플러그인
특정 이벤트(세션 시작, 파일 편집 등)에 자동으로 실행되는 스크립트를 제공합니다.

**예시**: `security-guidance` - 파일 편집 시 보안 경고 표시

### 4. 복합형 플러그인
Commands + Agents를 함께 제공하는 통합 플러그인입니다.

**예시**: `feature-dev` - 기능 개발 명령어 + 전문 에이전트들

## 프로젝트의 플러그인 구조

```
/home/user/claude-code/
├── .claude-plugin/
│   └── marketplace.json              # 마켓플레이스 설정 파일
└── plugins/                          # 플러그인 디렉토리
    ├── README.md                     # 플러그인 개요
    ├── agent-sdk-dev/                # Agent SDK 개발 도구
    ├── code-review/                  # PR 자동 코드 리뷰
    ├── commit-commands/              # Git 워크플로우 명령어
    ├── explanatory-output-style/     # 설명적 출력 스타일
    ├── feature-dev/                  # 기능 개발 워크플로우
    ├── learning-output-style/        # 학습 모드
    ├── pr-review-toolkit/            # PR 검토 도구 모음
    └── security-guidance/            # 보안 가이드
```

## 설치된 플러그인 목록

### 개발 도구 (Development)

#### 1. agent-sdk-dev
- **설명**: Agent SDK 애플리케이션 생성 및 검증 도구
- **제공 기능**:
  - 명령어: `/new-sdk-app` - 새 SDK 앱 생성
  - 에이전트: `agent-sdk-verifier-py`, `agent-sdk-verifier-ts`
- **위치**: `plugins/agent-sdk-dev/`

#### 2. feature-dev
- **설명**: 체계적인 기능 개발 워크플로우
- **제공 기능**:
  - 명령어: `/feature-dev` - 7단계 기능 개발 프로세스
  - 에이전트: `code-explorer`, `code-architect`, `code-reviewer`
- **특징**: Discovery → Exploration → Questions → Design → Implementation → Review → Summary
- **위치**: `plugins/feature-dev/`

### 생산성 도구 (Productivity)

#### 3. commit-commands
- **설명**: Git 워크플로우 자동화
- **제공 명령어**:
  - `/commit` - 자동 커밋 메시지 생성
  - `/commit-push-pr` - 커밋 + 푸시 + PR 생성 일괄 처리
  - `/clean_gone` - 삭제된 브랜치 정리
- **위치**: `plugins/commit-commands/`

#### 4. pr-review-toolkit
- **설명**: 6가지 전문 PR 검토 에이전트
- **제공 에이전트**:
  - `comment-analyzer` - 주석 정확성 검토
  - `pr-test-analyzer` - 테스트 커버리지 분석
  - `silent-failure-hunter` - 에러 처리 분석
  - `type-design-analyzer` - 타입 설계 검토
  - `code-reviewer` - 일반 코드 검토
  - `code-simplifier` - 코드 단순화 제안
- **위치**: `plugins/pr-review-toolkit/`

#### 5. code-review
- **설명**: PR 자동 코드 검토 (4개 병렬 에이전트)
- **제공 명령어**: `/code-review`
- **특징**: 신뢰도 점수 기반 필터링 (80 이상만 포스트)
- **위치**: `plugins/code-review/`

### 보안 도구 (Security)

#### 6. security-guidance
- **설명**: 파일 편집 시 보안 경고
- **제공 기능**: PreToolUse Hook (Edit/Write 시 자동 실행)
- **감지 패턴**:
  - Command Injection
  - XSS (dangerouslySetInnerHTML, innerHTML)
  - Code Injection (eval, new Function)
  - GitHub Actions 워크플로우 보안
  - Pickle deserialization
- **위치**: `plugins/security-guidance/`

### 학습 도구 (Learning)

#### 7. learning-output-style
- **설명**: 대화형 학습 모드
- **제공 기능**: SessionStart Hook
- **특징**: 의사결정 지점에서 사용자에게 5-10줄 코드 작성 요청
- **위치**: `plugins/learning-output-style/`

#### 8. explanatory-output-style
- **설명**: 설명적 출력 스타일
- **제공 기능**: SessionStart Hook
- **특징**: 구현 선택사항에 대한 교육적 통찰력 제공
- **위치**: `plugins/explanatory-output-style/`
